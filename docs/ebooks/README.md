# Coleção de ebooks — 3 produtos para Kiwify

Três ebooks independentes (3 ofertas separadas), redigidos com voz comum, honestos por design
(sem promessa de ganho), com disclaimers e jogo responsável. Formam uma esteira: quem compra um
é alvo natural dos outros.

| Pasta | Título | Foco | Tamanho |
|---|---|---|---|
| [`sportsbook/`](sportsbook/) | **Sportsbook com Método** | 3 pilares: value betting, bônus/matched, gestão de banca | ~10.500 palavras |
| [`cassino/`](cassino/) | **Cassino com Consciência** | Verdade matemática, RTP, bônus, perder menos, jogo responsável | ~6.700 palavras |
| [`bolao/`](bolao/) | **Bolão da Copa com Estratégia** | Previsão, EV/contrarian, montar/operar bolão | ~7.800 palavras |

Cada pasta tem 4 partes (`00`–`03`) + `_CAPA-E-KIWIFY.md` (título, conceito de capa, descrição
pra Kiwify, preço sugerido, disclaimers).

## Padrão de honestidade (auditado nos 3)
Sem promessa de lucro garantido · números rotulados como ilustrativos · 18+ · jogo responsável +
canais de ajuda (Jogadores Anônimos; CVV 188) · cassino deixa explícito que a casa vence no longo
prazo · bolão deixa explícito que a variância domina.
